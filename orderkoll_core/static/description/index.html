Orderkoll

Emailed purchase orders into draft quotations, checked and approved by a person

Your customers email purchase orders as PDF, Excel, CSV or plain text, and someone retypes them into Odoo. Orderkoll takes each mail, keeps the original file, finds the customer from the sender, matches their item codes to your products, and prepares a document that a person reviews before a quotation exists. Nothing is confirmed automatically.

The review screen

The purchase order beside its lines, and a plain-language To-do box that says what stops it. Here one item code is unknown: click Map, pick the product once, and Orderkoll remembers it for this customer.

What the free module does

  • Intake from a mail alias (Odoo's own incoming mail) or by IMAP from a mailbox that only receives purchase orders
  • One document per mail: the original file, the sender, and the text extracted from it (text PDFs, Excel, CSV, the email body; scanned PDFs through optional OCR, always routed to a person)
  • The customer from the sender: exact email, then domain, never webmail domains
  • Each line's product: customer code memory, internal reference, barcode, then name similarity
  • Review screen with Map product, Pick customer and Reject with a reason; every edit re-runs the checks
  • Create quotation: a draft sales order with the PO number as customer reference, the original file attached and every check in the chatter
  • A task for the responsible person when a document fails, optional Telegram or webhook alerts, and a heartbeat URL for your monitor
  • Two user groups (order desk, manager) and per-company rules

What it does not do on its own

Reading the order lines out of the document needs an extraction engine. Without one, the lines are typed on the review screen and everything else above works the same. The AI extraction engine and the price, totals and duplicate checks are in the separate module Orderkoll Pro.

Your data

The free module sends nothing outside your Odoo, except the alerts you switch on yourself (Telegram, or a webhook URL you enter), which carry only the document number, the inbox name and a link back to it.

Customer code memory: each customer's own item codes, mapped once.

Compatibility

Odoo 20.0 Community, on your own server. Odoo Online does not allow custom modules. Python packages: pdfplumber, pypdf, openpyxl; optional pytesseract with Tesseract for scanned PDFs.
